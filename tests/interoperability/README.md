# Testes de Interoperabilidade (`tests/interoperability/`)

Testes de interoperabilidade com clientes e plataformas FIDO2 reais:

- Chromium / Chrome WebAuthn
- Firefox WebAuthn
- Windows Hello
- Android FIDO2
- Python `fido2` library

Garante conformidade com as especificações FIDO Alliance e W3C WebAuthn Level 2/3.
