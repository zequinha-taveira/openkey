# Testes de Hardware (`tests/hardware/`)

Testes que requerem hardware físico OpenKey conectado via USB.

**Pré-requisito**: Dispositivo OpenKey (RP2350 ou compatível) conectado.

Cobre:
- TRNG health check
- Flash write/read/erase cycle
- USB HID packet integrity
- Watchdog reset behavior
- User presence (touch) detection
