OpenKey is an open-source universal FIDO2/WebAuthn hardware security key
framework developed in Rust. It provides a memory-safe, auditable firmware
that runs on existing development boards (RP2350, RP2040, ESP32-S3, STM32,
nRF52/nRF54) without requiring custom hardware.
