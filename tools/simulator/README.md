# OpenKey Host Simulator (`tools/simulator/`)

Simulador em nível de software da chave de segurança FIDO2 OpenKey.
Permite testar comandos CTAP2, WebAuthn e simular toques de presença
sem necessidade do dispositivo de hardware físico.

Migrado de `host/simulator/`.

Consulte [`docs/development/testing.md`](../../docs/development/testing.md)
para aprender a executar o simulador localmente.
