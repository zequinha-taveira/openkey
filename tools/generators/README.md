# Geradores (`tools/generators/`)

Ferramentas de geração automática:

- Geração de Board Profiles YAML a partir de especificações de hardware.
- Geração de documentação de API a partir de código Rust (rustdoc → markdown).
- Geração de certificados de atestado para fábrica.
- Geração de stubs de HAL para novos MCUs.
