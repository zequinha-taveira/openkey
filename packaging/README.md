# Empacotamento (`packaging/`)

Artefatos e scripts de empacotamento para distribuição do OpenKey:

- **Linux**: `.deb` (Debian/Ubuntu), `.rpm` (Fedora/RHEL), `.tar.gz`
- **macOS**: `.pkg`, `.dmg`, Homebrew formula
- **Windows**: `.msi`, `.exe` (NSIS), WinGet manifest
- **Python**: `pyproject.toml` / `setup.py` para `openkey-sdk` no PyPI

Cada subdiretório corresponde a uma plataforma ou formato de pacote.
