# OpenKey Host SDK (`host/sdk/`)

Biblioteca cliente para comunicação com dispositivos OpenKey e simuladores FIDO2 via USB HID / NFC.

## Recurso

- Bindings nativos em Rust e Python (`openkey-sdk`).
- Abstração cruzada de plataformas (Windows, Linux, macOS).
- Suporte a operações CTAP2 (MakeCredential, GetAssertion, ClientPin, Reset).

Documentação da API em [`docs/api/python-sdk.md`](../../docs/api/python-sdk.md) e [`docs/architecture/host-sdk.md`](../../docs/architecture/host-sdk.md).
