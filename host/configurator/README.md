# OpenKey Configurator (`host/configurator/`)

Aplicativo gráfico para Windows, macOS e Linux que oferece interface amigável
para gerenciamento e configuração de chaves OpenKey:

- Configuração de PIN e políticas de segurança.
- Gerenciamento de Credenciais Residentes (RK).
- Provisionamento de Board Profile e Device Profile.
- Visualização de logs e diagnósticos.

Documentação técnica em [`docs/api/configurator.md`](../../docs/api/).
