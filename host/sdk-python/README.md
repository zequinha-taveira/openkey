# OpenKey Python SDK (`host/sdk-python/`)

Biblioteca cliente Python para comunicação com dispositivos OpenKey e simuladores
FIDO2 via USB HID / NFC.

## Recursos

- API Python para operações CTAP2 (`MakeCredential`, `GetAssertion`, `ClientPin`, `Reset`).
- Abstração multiplataforma (Windows, Linux, macOS).
- Suporte a transporte USB HID e NFC.

## Instalação

```bash
pip install openkey-sdk
```

Documentação da API em [`docs/api/python-sdk.md`](../../docs/api/python-sdk.md).
