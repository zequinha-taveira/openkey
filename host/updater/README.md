# OpenKey Updater (`host/updater/`)

Ferramenta de atualização segura de firmware (DFU) para chaves OpenKey:

- Verifica a assinatura criptográfica do firmware antes da instalação.
- Suporta atualização via USB HID (CTAP2 Vendor Command).
- Realiza rollback automático em caso de falha.
- Compatível com Windows, Linux e macOS.

Consulte [`docs/how-to/firmware-update.md`](../../docs/how-to/) para instruções.
