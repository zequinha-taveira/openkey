# OpenKey Diagnostics (`host/diagnostics/`)

Ferramenta de diagnóstico e análise de chaves OpenKey:

- Leitura de logs e eventos do dispositivo.
- Teste de integridade de flash e RNG.
- Verificação de conformidade FIDO2/CTAP2.
- Geração de relatórios de diagnóstico.

Consulte [`docs/how-to/diagnostics.md`](../../docs/how-to/) para instruções.
