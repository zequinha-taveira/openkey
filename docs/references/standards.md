# Padrões e Normas Técnicas de Referência (`docs/references/standards.md`)

## 📜 Normas Internacionais e Especificações

O OpenKey é desenvolvido estritamente de acordo com as especificações normativas das seguintes organizações internacionais:

### 🌐 FIDO Alliance
- **FIDO CTAP 2.0 / 2.1**: *Client to Authenticator Protocol Specification*.
- **FIDO Authenticator Attestation**: *FIDO Metadata Service & Attestation Formats*.

### 🌐 W3C (World Wide Web Consortium)
- **WebAuthentication (WebAuthn) Level 2 & Level 3**: *An API for accessing Public Key Cryptography Credentials*.

### 🌐 USB Implementers Forum (USB-IF)
- **Device Class Definition for Human Interface Devices (HID)**: Version 1.11.
- **FIDO Universal Second Factor (U2F) / CTAP USB Interface Spec**.

### 🌐 IETF (Internet Engineering Task Force)
- **RFC 8949**: *Concise Binary Object Representation (CBOR)*.
- **RFC 8152 / RFC 9052**: *CBOR Object Signing and Encryption (COSE)*.
- **RFC 5480**: *Elliptic Curve Cryptography Subject Public Key Information*.

### 🌐 NIST (National Institute of Standards and Technology)
- **NIST SP 800-90B**: *Recommendation for the Entropy Sources Used for Random Number Generation*.
- **FIPS 186-4**: *Digital Signature Standard (DSS)*.
