# Plano de Desenvolvimento do OpenKey

## 📌 Visão Geral

O desenvolvimento do OpenKey segue um plano incremental de 12 fases,
avançando de um framework de firmware básico até um ecossistema completo
com certificação FIDO Alliance.

Cada fase adiciona funcionalidade enquanto mantém a estabilidade das fases anteriores.

## 📋 Fases

| Fase | Descrição | Status |
|------|-----------|--------|
| 1 | Estrutura base e HAL | ✅ Concluído |
| 2 | Protocolos CTAP2 e CBOR | 🔄 Em progresso |
| 3 | USB HID e transporte | 📋 Planejado |
| 4 | Criptografia e chaves | 📋 Planejado |
| 5 | Armazenamento e credenciais | 📋 Planejado |
| 6 | Host SDK e CLI | 📋 Planejado |
| 7 | Configurator (GUI) | 📋 Planejado |
| 8 | Provisionamento de fábrica | 📋 Planejado |
| 9 | Atualização de firmware (DFU) | 📋 Planejado |
| 10 | Testes de interoperabilidade | 📋 Planejado |
| 11 | Suporte a múltiplos MCUs | 📋 Planejado |
| 12 | Certificação FIDO Alliance | 📋 Planejado |
