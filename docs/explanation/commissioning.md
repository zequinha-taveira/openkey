# Comissionamento

## Visão Geral

Processo de preparo do dispositivo para uso.

## Etapas

1. **Provisionamento** - Configuração inicial
2. **Teste** - Verificação de funcionamento
3. **Ativação** - Pronto para uso

## Testes Recomendados

- Enumerção USB HID
- Resposta a `authenticatorGetInfo`
- Criação de credencial
- Autenticação
- Reset de fábrica

## Ferramentas

- `openkey-cli diagnostics`
- Navegador Web (WebAuthn)
- Simulador
