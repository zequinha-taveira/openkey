# Diagramas (`docs/diagrams/`)

Diagramas de arquitetura e fluxos do OpenKey em formato `.drawio`
(editáveis com [draw.io / diagrams.net](https://app.diagrams.net/)).

## Conteúdo

| Arquivo | Descrição |
|---------|-----------|
| `architecture.drawio` | Arquitetura em camadas do framework OpenKey |
| `provisioning.drawio` | Fluxo de provisionamento de fábrica |
| `storage.drawio` | Layout de memória Flash e wear-leveling |
| `usb.drawio` | Stack USB HID e framing CTAPHID |
| `startup.drawio` | Sequência de inicialização (boot → firmware) |

## Como editar

1. Abra o arquivo `.drawio` em [diagrams.net](https://app.diagrams.net/)
2. Edite os diagramas
3. Exporte como PNG para uso em documentação (opcional)
4. Faça commit do `.drawio` atualizado
