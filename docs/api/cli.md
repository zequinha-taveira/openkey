# Comandos da Interface CLI (`docs/api/cli.md`)

## 💻 Ferramenta `openkey-cli`

### Lista de Comandos

```bash
# Obter informações do autenticador
openkey-cli info

# Alterar ou cadastrar PIN do usuário
openkey-cli pin set

# Listar credenciais residentes
openkey-cli credentials list

# Atualizar firmware via arquivo DFU assinado
openkey-cli flash update --file firmware.bin
```
